# Comandas Marquezine

App de controle de comandas (HTML + CSS + JavaScript puros, sem build).

## Estrutura
- `index.html` — página principal
- `css/style.css` — estilos e efeitos de luz
- `js/app.js` — lógica (contagem, histórico com abas, gráficos, tela final em 3D, configurações, CSV)
- `assets/comanda.webp` — imagem da comanda (recortada, sem fundo)

## Publicar no GitHub Pages
1. Envie todo o conteúdo desta pasta para um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. Abra o link gerado pelo GitHub.

Os dados ficam salvos no navegador (localStorage). A sincronização com Firebase fica para a próxima etapa.
